# NOE v2.12.0

This release adopts native Go JSON v2 behavior across NOE-owned processing
and improves timer and Streams resource management. Go 1.27.2, go-quickjs
v0.32.0, go-intl v0.8.0, and disabled JIT remain unchanged.

## Native JSON v2

NOE core, the public stdlib loader, and agentlib now use `encoding/json/v2`
with native defaults. Provider SDKs retain their own serialization. Every
agent provider remains behind the shared agent library, including OpenAI API,
ChatGPT OAuth, OpenRouter, and OpenCodeGo.

JSON input rejects duplicate object names and invalid UTF-8 by default.
Struct-field matching is case-sensitive. Nil collections normally encode as
`[]` or `{}`, HTML characters are not escaped by default, and object-member
ordering is unspecified. Consumers should compare parsed objects and use
documented JSON field names. Deterministic serialization remains where
serialized bytes identify profile-cache entries.

Explicit zero limits, false values, empty answers and hook collections,
`null`/`[]`/`{}` result data, exact generic numeric values, and inherited
versus explicitly empty process environments retain their intended meaning.
Public Go `RawMessage` and `Number` field types remain source-compatible.
JavaScript `JSON.parse` and `JSON.stringify` are unchanged.

Event output remains complete, single-write JSONL records with nanosecond
durations. Binary output remains byte-preserving; its JSON text projection
replaces invalid UTF-8 while preserving valid characters split across writes.
See the [migration note](../development/json-v2-migration.md) for contracts
and verification details.

## Timer and Streams improvements

The event loop reuses wait timers, and cancelled JavaScript timers leave the
timer heap immediately. ReadableStream queues use head indices to avoid
repeated array shifting. Compression removes an intermediate byte copy.
Decompression processes input incrementally with output demand and
cancellation, retaining the existing cumulative 1 GiB output limit.

TransformStream now applies readable-side backpressure, including native
text and compression wrappers. The default readable high-water mark is zero.
Code manually writing to a transform must consume its output concurrently;
awaiting every write before starting reads can wait indefinitely. Start the
reader first or connect the stream with `pipeThrough`/`pipeTo`. Cancellation,
startup, transform, flush, and enqueue failures release pending operations.

These are NOE's maintained stdlib improvements. Upstream contribution notes
are retained in [UPSTREAM.md](../../internal/stdlib/UPSTREAM.md); no upstream
issue or pull request has been submitted.

## Verification and distribution

Implementation checks covered whole-tree unit/local CLI E2E, broad race
checks, public Go consumers, vet, TypeScript declarations, embedded-JavaScript
lint, and focused regressions. Three test assumptions exposed by the JSON
migration were corrected and their affected normal/race cases rerun;
passing checks for unchanged production sources were reused.

Six live-provider JSON cases passed: OpenCodeGo Chat and Responses,
OpenRouter Chat, OpenAI API Responses, ChatGPT OAuth Responses, and the
public Go agent client using OpenRouter. Fourteen model calls and twelve
tool executions verified JSON values, hook-modified tool results reaching
the provider, snapshots, JSONL events, and typed Go result retrieval. These
were successful dummy-task exchanges, not exhaustive provider testing.

Release preparation reuses this evidence and performs lightweight version,
native build, and smoke checks. CI builds six CGO-free targets and publishes
SHA256SUMS. Published assets, build records, native behavior, and external Go
consumers are checked before local executable placement. Existing processes
adopt the new executable on their next normal restart.

See the [release checkpoints](release-checkpoints.md).
