# NOE v1.5.0

This release adds agent hooks, execution-group tracking and optional shared limits, context-budget notifications, and automatic instruction loading. It also includes a reusable Exa search library example.

## Agent hooks and shared execution control

- Register local ESM modules with `hooks: ["./hooks.js"]`. Export `beforeModelRequest`, `afterModelResponse`, `beforeTool`, and `afterTool` as needed. Hooks receive a snapshot of the event and APIs bound to that invocation.
- Use `api.agents` for existing agent operations, `api.context` for current input-budget information, and `api.execution` for group counters and causal metadata. Children inherit the hook list unless replaced or cleared with `[]`.
- Preserve original provider responses and reasoning. Tool hooks can replace arguments and model-facing results; observations retain the original arguments and actual execution results separately.
- Track a root, its descendants, and queued tasks in one execution group. Events include activity IDs, causes, origins, and counters so supervisors can follow the chain of work.
- Optionally set root `executionLimits` for `providerCalls`, `agentStarts`, `queuedTasks`, and `hookCalls`. Admission is atomic across the group. Exceeding a configured limit stops that group and reclaims owned work; independent roots continue. Omitted limits remain unlimited, and zero admits no work in that dimension.

See the [hook guide](https://forge.harakara.site/littleisland/noe/src/tag/v1.5.0/docs/hooks.md) and [example](https://forge.harakara.site/littleisland/noe/src/tag/v1.5.0/examples/agent-hooks.js).

## Context budgets and observation

- Set `contextBudget: {inputTokens: 200000}` to make an input budget visible to the model, hooks, supervisors, and human observers. Children inherit it unless explicitly cleared with `null`.
- Keep measured prompt/cached usage separate from the next request's approximate input size. Unknown values remain unknown; estimates use JSON UTF-8 bytes divided by four.
- Add one context-status notification to each outgoing request without accumulating it in conversation history. `beforeModelRequest` hooks can add other request-scoped text through `api.context.setRuntimeInfo({key, text})`.
- Show context and hook activity in readable observation output and retain snapshots in live and saved observation. Saved tool payloads require `includeOutput: true`; raw JSONL retains execution details.

An input budget alone does not stop a task or compress history. Automatic context compression remains unimplemented. See the [observation guide](https://forge.harakara.site/littleisland/noe/src/tag/v1.5.0/docs/observe.md).

## Automatic instructions

At the start of each task run, append Markdown instructions in this order:

1. NOE's built-in instructions.
2. `*.md` in `$XDG_CONFIG_HOME/noe/instructions/`, or `~/.config/noe/instructions/` when XDG is unset or empty.
3. `*.md` in `.noe/instructions/` under NOE's startup working directory.
4. Explicit `config.system` text.

Files are sorted by name within each directory. Matching names append both files. Each run freezes the resulting text; a new child run or subsequent queue task reads a fresh snapshot. Missing directories add nothing, while instruction read errors fail the task before hooks or provider calls. Idle instances without a task do not read instructions. Git-root, ancestor-directory, and `AGENTS.md` discovery are not added.

Arbitrary files, including multiple files, can still be read and joined by JavaScript before passing their text to `system`. See the [instruction guide](https://forge.harakara.site/littleisland/noe/src/tag/v1.5.0/docs/instructions.md).

## Exa library example

The [Exa library](https://forge.harakara.site/littleisland/noe/src/tag/v1.5.0/examples/exa.js) exports `search(query, options)` using NOE's `fetch`. Its [guide](https://forge.harakara.site/littleisland/noe/src/tag/v1.5.0/examples/exa.md) explains import maps, key-file configuration, unmodified response JSON, and errors. Importing the library does not read a key or send a request. Its default key path is `~/.config/noe/credentials/exa-api-key`; this example does not yet follow XDG automatically.

## Validation and downloads

Each implementation slice received tests and code review, followed by integration, race, and overall review. OpenCode Go / DeepSeek V4.1 Flash live acceptance covered six hook/context/ownership/control/limit scenarios; failed attempts and retries are recorded separately. The Exa example passed local mock tests and one authorized real search. These checks do not imply native execution on every distribution target.

Release checks include unit tests, Linux PTY E2E, vet, race detection, and six CGO-free builds. Dependency versions are unchanged from v1.4.0. Standalone binaries cover Linux, macOS, and Windows on amd64 and arm64, with `SHA256SUMS`. See the [release checkpoints](https://forge.harakara.site/littleisland/noe/src/tag/v1.5.0/docs/release-checkpoints.md).
