# NOE v2.28.0

This release adds batched SQLite row iteration, improves binary-data contracts
and context preparation, and corrects stream cleanup and reasoning observations.

## SQLite row iteration

Database and transaction handles now expose
`iterate(sql, params, {batchSize, signal})`; prepared statements expose
`iterate(params, options)`. These return lazy async iterators directly, fetching
at most 128 rows per batch by default rather than collecting the whole result.
Preparation and execution start on the first next call. Existing all/get/run
callers need no migration.

EOF, loop break, return, close, async disposal, cancellation, and owner shutdown
release cursors. Transaction-local iterators close when their callback ends;
caught SQL errors and iterator cancellations still cause rollback. Other SQL
can run between batches. Reusing a prepared statement with an active native
cursor rejects with ERR_SQLITE_BUSY until it is released.

The batch bound counts rows, not bytes or SQLite query workspace. Early close
does not undo writes from RETURNING; use a transaction for rollback. See the
[API reference](../../internal/apidocs/content/noe-sqlite.md#databaseiterate),
[implementation record](../development/stdlib-sqlite.md#batched-row-iteration--2026-11-17),
and [CSV export example](../../examples/sqlite/README.md).

## Blob, File, and FormData

Binary data now uses private immutable backing storage. Derived Blobs, slices,
and Files with new names share that storage, while author-visible reads and
stream chunks receive independent bytes. Fetch, multipart, WebSocket, and
structured cloning use the same private data path. FormData iteration observes
live changes. The improvement reduces derived-data copying; slices can still
retain their larger original allocation.

Compatibility changes follow the supported Web contracts:

- Replace `new Blob(text)` with `new Blob([text])`.
- File requires parts and a filename. Text/name conversions, MIME types,
  lastModified, and native text endings follow their documented contracts.
- A filename argument to FormData append/set requires a Blob, even when that
  third argument is undefined.
- Internal-looking properties such as `_bytes`, `_type`, and `_entries` no
  longer supply native state.

See the [reference](../../internal/apidocs/content/stdlib-globals.md#blob) and
[implementation and measurement record](../development/stdlib-handoff.md#previous-continuation--binary-data-contracts-and-context-analysis-reuse).

## Stream cleanup and agent preparation

ReadableStream async iterators release reader ownership on EOF and read errors.
Early return releases the lock before source cleanup settles and propagates
cleanup failure. Iterator calls are serialized. Callers should handle a failed
return or loop break when source cancellation fails.

Managed agent runs reuse context analysis for an unchanged owned snapshot and
revision. Trim and run completion release obsolete references. Unmanaged input
still receives full validation. Cache-hit preparation of the recorded
256-message fixture improved from 4.69 ms to 1.35 ms, excluding model/network
time; this is not a whole-run latency claim. See the
[analysis cache record](../development/agentlib-optimization.md#revision-scoped-preparation-reuse--2026-11-17).

Chat observations respect the configured reasoningField, including
reasoning_content and custom fields. A configured field no longer falls back
to another top-level alias when absent. Opaque reasoning and request payloads
are unchanged. See the [provider guide](../providers.md).

## Verification and distribution

Implementation verification includes whole-tree unit/E2E, focused SQLite and
binary/context race checks, vet, TypeScript fixtures, JS lint, embedded API
checks, and independent stdlib/agent Go consumers. The final transaction
cleanup guard was checked by all SQLite tests with race detection and repeated
external stdlib consumers; its regression fails without the guard and passes
20 consecutive runs with it. Unchanged completed checks are reused.

Dependencies remain unchanged, including go-quickjs v0.38.0 with JIT disabled.
No paid provider request is needed for release verification. CI builds the
six distribution binaries and SHA256SUMS from the immutable tag without
repeating source suites. Publication includes verified installation at both
existing vm201 executable paths, retaining the previous binaries. See the
[release checkpoints](release-checkpoints.md).
