# NOE v2.26.1

NOE's built-in agent instructions now identify JavaScript as the primary
programming language for task logic, data processing, and automation. The
guidance is embedded in the executable and supplied to Go-hosted agents as
well as CLI agents, including with `--no-inst` or no external instruction files.

Agents can still use another language when requested by the user, required by
the target project, or concretely beneficial for the task. Existing command-line
tools remain available through the selected execution profile's APIs.

The instruction guide, API guide, and CLI help describe the built-in guidance.
Public Go/JavaScript APIs, runtime behavior, dependencies, and the remaining
external behavioral preferences are unchanged.

Focused implementation checks cover Go-host instruction composition, external
instruction replacement/removal, parent/child snapshots, API-reference lookup,
and CLI composition with external instructions disabled. Release verification
checks the native binary and the built-in guidance in a loopback model request.
Existing checks for unchanged source and dependencies are reused; CI builds the
six distribution binaries and SHA256SUMS without repeating source suites.

Publication includes verified local installation at both existing vm201
executable paths, retaining the previous binaries. See the
[release checkpoints](release-checkpoints.md).
