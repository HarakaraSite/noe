# NOE v1.6.1

This release fixes queued tasks starting with an empty conversation. A keepAlive agent now continues its previous work when it receives another instruction through `queue_agent` or `noe queue`.

## Continuing queued work

- Preserve the conversation that survived context trimming, including completed tool exchanges, previous final answers, reasoning, signatures, and native provider fields.
- Append each queued instruction as a protected user message when its task starts. Pending tasks do not change the current task's conversation. Original instructions, applied steers, and started queue instructions remain protected from trimming, in their original order and roles.
- Carry trim counts and the latest trim state forward. Removed history stays removed, and already delivered trim notices do not replay.
- Compose system instructions once for the instance's first task. Later queue tasks keep that system without rereading instruction files. New agents, including children, load their own instructions and have independent conversations.
- Continue from the last committed complete history after task failure or run interruption. Partial tool exchanges are not restored. Whole-instance interruption still cancels queued work and releases the conversation.

Each queued task still has a new run ID, its own `maxSteps` counter and cancellation scope, a fresh runtime, and fresh hook-module state. Existing cache/session-key behavior is unchanged. This is in-memory continuation within the same agent instance; it does not resume an agent after NOE exits.

## Validation and downloads

Fixtures exercise queue continuation, full provider fields, system freezing, run-local steering IDs, trimming across queued tasks, failures, tool interruption, and human CLI controls. README and API guides describe the corrected behavior. See the [implementation record](https://forge.harakara.site/littleisland/noe/src/tag/v1.6.1/docs/development/queue-continuation-implementation.md) and [release checks](https://forge.harakara.site/littleisland/noe/src/tag/v1.6.1/docs/releases/release-checkpoints.md).

Dependencies and the release workflow are unchanged from v1.6.0. Downloads cover Linux, macOS, and Windows on amd64 and arm64, with `SHA256SUMS`. Native execution is checked on Linux amd64; the other targets are cross-compiled.
