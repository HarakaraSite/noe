# NOE v1.3.1

NOE updates its JavaScript engine from go-quickjs v0.25.3 to v0.27.0, including the changes in v0.26.0. Agent startup and provider configuration remain the same as in v1.3.0.

## Engine update

The upstream release improves ordinary JavaScript execution and reduces allocations and object sizes. It also fixes resource-disposal scheduling, timer ordering, regular-expression interruption, and other language behavior. Performance figures in the [upstream v0.27.0 release notes](https://github.com/go-quickjs/go-quickjs/releases/tag/v0.27.0) are upstream measurements; this release does not claim a measured speedup for NOE agent tasks.

- NOE explicitly keeps the previous unlimited JavaScript Worker count with `Workers.Max: -1`, rather than adopting v0.27.0's default limit of 64. This setting concerns JavaScript Workers, separate from agent delegation.
- The five qjs-derived REPL input/editor/terminal files are unchanged upstream from v0.25.3 through v0.27.0. NOE retains its existing snapshot and local adaptations.
- Upstream behavior fixes apply, including `await using` disposal timing, timer delays beyond 2³¹−1 milliseconds running as soon as possible, and accurate Fetch `response.redirected` values.

The new optional native JIT and `Runtime.OnUncaughtException` API are not enabled by this update. NOE's existing stdlib exception handling remains in use.

## Validation and downloads

Both v0.26.0 and v0.27.0 passed NOE's full fixture and CLI/REPL E2E suite during compatibility checking. Release checks cover the final updated dependency and a regression test that starts and terminates 65 concurrent JavaScript Workers. See the [release checkpoints](https://forge.harakara.site/littleisland/noe/src/tag/v1.3.1/docs/releases/release-checkpoints.md) for the recorded source revision and results.

Six standalone binaries cover Linux, macOS, and Windows on amd64 and arm64, with `SHA256SUMS`. Linux amd64 is tested natively; other platforms are cross-compiled. The [README](https://forge.harakara.site/littleisland/noe/src/tag/v1.3.1/README.md) and [Japanese README](https://forge.harakara.site/littleisland/noe/src/tag/v1.3.1/README.ja.md) describe agent setup and execution.
