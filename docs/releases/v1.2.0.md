# NOE v1.2.0

NOE now runs autonomous agent tasks from JavaScript through the built-in `noe:agent` module. OpenRouter is the first supported provider, using the official OpenRouter Go SDK. Existing JavaScript scripts and the CLI/REPL remain available.

## Autonomous tasks

```js
import { createAgent } from "noe:agent";

const agent = createAgent({ model: "deepseek/deepseek-v4.1-flash" });
const answer = await agent.run("Read README.md and write a summary to SUMMARY.md.");
console.log(answer);
```

The model receives one tool, `run_js`, which executes JavaScript in a fresh NOE process. It can read and write files, run commands, inspect failed results, and repair its code without waiting for human input. Generated JavaScript can create child agents and run them concurrently with `Promise.all`.

Go owns credentials, provider communication, and process supervision; the loop runs in JavaScript. Each run has independent history, with no persistent conversation or resume feature. Child agents inherit provider, model, and `maxTokens` unless explicitly overridden. Optional `maxSteps`, `maxTokens`, and the existing CLI `--timeout` provide limits; NOE adds no default step or delegation-depth limit.

## Authentication and observation

Point `NOE_OPENROUTER_API_KEY_FILE` to a text file containing the API key. Otherwise NOE uses `$XDG_CONFIG_HOME/noe/credentials/openrouter-api-key`, or `~/.config/noe/credentials/openrouter-api-key` when XDG is unset. Credentials are read lazily by Go on the first model request.

`NOE_AGENT_TRACE=1` writes JSON Lines metadata to stderr: run/parent IDs, model, status, duration, returned usage/cache/cost, and JavaScript exit results. Save stdout and stderr separately to retain both answers and execution logs. Diagnostics may also appear on stderr; generated code, tool output, and API keys are not part of trace records.

The [README](https://forge.harakara.site/littleisland/noe/src/tag/v1.2.0/README.md) includes setup and observation commands. [Examples](https://forge.harakara.site/littleisland/noe/src/tag/v1.2.0/examples/README.md) cover summaries and parallel children, and `try-agent.js` accepts arbitrary tasks. The [API reference](https://forge.harakara.site/littleisland/noe/src/tag/v1.2.0/docs/api.md) documents options, errors, cancellation, and REPL use.

## Validation and scope

Local fixture and CLI/PTY tests cover tool/history preservation, autonomous repair, parallel children, context cancellation, and process cleanup. Live OpenRouter tests with `deepseek/deepseek-v4.1-flash` verified aggregation, repair, and parallel delegation. A separate live task read and edited README.md, then reread it to confirm the edit. These observations do not guarantee future model output, exact JSON, or cache hits.

Agents run with the current user's OS permissions. Content used for a task can be sent to OpenRouter. Workers do not support `noe:agent`; additional providers, subscription OAuth, built-in web search, and persistent conversations are outside this release.

## Downloads

Standalone binaries are provided for Linux, macOS, and Windows on amd64 and arm64, plus `SHA256SUMS`. No separate JavaScript engine installation is needed. Linux amd64 is tested natively; macOS, Windows, and arm64 builds are cross-compiled, with native runtime behavior unverified here.
