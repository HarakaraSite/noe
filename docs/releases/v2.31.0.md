# NOE v2.31.0

## Saved agent tool output

Set `NOE_AGENT_TOOL_OUTPUT_DIR` to an existing directory for CLI runs, or set
`agent.HostConfig.ToolOutputDir` when embedding the agent in Go. When
`run_js` stdout or stderr exceeds its capture budget, NOE saves that stream
in full and keeps the bounded head and tail preview. Saving is opt-in.

The `stdoutFile` and `stderrFile` references include a path and byte count.
A later tool can read the omitted range with `noe:fs`. The references also
appear in live observation and execution logs. Saved files persist after
the run, and the caller manages retention. See the
[saved stream contract](../execution-results.md#saved-stream-output).

## Provider retry and context estimates

- Model requests honor bounded provider retry delays and distinguish
  transient usage lookups from quota exhaustion. Each logical request still
  allows up to three transport attempts.
- The context estimate uses the provider's reported input tokens for an
  unchanged prefix and estimates subsequent additions. Display and automatic
  trim use the same total.

See the [retry and context design](../development/agentlib-retry-context.md).

## Built-in model catalog

GPT-6.2 Sol and GPT-6.2 Astra are listed for `openai-chatgpt`, `openai-api`,
and `openrouter`. The entries include text and image input, tool support,
reasoning effort, and context limits. See the
[catalog metadata](../model-catalog.md).

## Distribution

The release includes Linux, macOS, and Windows binaries for amd64 and arm64,
plus `SHA256SUMS`. Go users can select the tag for the
`forge.harakara.site/littleisland/noe/v2` module.
