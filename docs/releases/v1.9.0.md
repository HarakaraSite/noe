# NOE v1.9.0

This release removes the interactive REPL and its dedicated implementation. Use a JavaScript file with `noe run` for repeatable work, or `noe eval` for short expressions and scripts.

## CLI migration

`noe repl` is no longer a command. It reports an unknown command and exits with code 2. Invoking `noe` without arguments still displays help.

```sh
noe run script.js
noe eval 'const value = await Promise.resolve(42); console.log(value);'
noe docs noe:sockets connect
```

REPL-specific variable persistence, the previous-value `_`, multiline prompts, Tab completion, input history, and recovery between inputs are removed. Keep related operations in the same script when they need shared state. `NOE_REPL_HISTORY` is no longer used; existing history files are left in place.

`run` and `eval` retain top-level await, import maps, standard input as script data, execution timeouts, and SIGINT cancellation. Workers, agents, `run_js`, bundled API docs, and owned I/O retain their existing contracts. The REPL line editor, Session implementation, recovery helpers, and tracking wrappers used only by the REPL have been deleted.

## Saved logs and documentation

New executions no longer emit `repl.result` or `repl.error`. `noe observe` continues to render those events in existing JSONL recordings. Current guides and examples use `run` and `eval`; historical REPL integration records remain archived.

See the [implementation and validation record](https://forge.harakara.site/littleisland/noe/src/tag/v1.9.0/docs/development/repl-removal-implementation.md). Unit tests, E2E, race detection, vet, and local provider/MCP fixtures verify the retained execution and cleanup paths. A process-test helper also handles `ESRCH` when a terminating process disappears during a procfs read; production process behavior is unchanged.

Dependencies and distribution targets are unchanged. Downloads cover Linux, macOS, and Windows on amd64 and arm64, with `SHA256SUMS`. Native execution is verified on Linux amd64; the other targets have cross-build evidence.
