# NOE v2.32.1

Managed OpenAI Responses sessions now retry when the provider reports
`websocket_connection_limit_reached`. NOE opens a new WebSocket and sends
the current conversation, including completed tool results. The same agent
task continues and each completed tool runs once.

Download binaries for Linux, macOS, and Windows on amd64 and arm64, along
with `SHA256SUMS`. The Go module is
`forge.harakara.site/littleisland/noe/v2`.
