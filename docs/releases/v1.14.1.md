# NOE v1.14.1

This patch improves agent observation and retries transient model-provider failures without replaying completed hooks or tools.

## Provider recovery

Built-in agent providers now make up to three attempts for transport failures, HTTP 429/5xx responses, and incomplete streams. The second attempt waits 2 seconds and the third waits 4 seconds. Existing cancellation, interrupt, and timeouts also stop retry waits. Authentication, quota, invalid-input, and cancellation errors are not retried.

Each attempt resends the same input with fresh response state. Failed partial responses never enter the conversation history, and incomplete tool calls never execute. Already observed thinking fragments remain visible and may repeat. Hooks and completed tools are not replayed. No retry-specific events or configuration options are added; model events, `maxSteps`, and provider admission counters retain their logical-request unit. Recorded usage contains only the successfully obtained response, not inferred usage from failed attempts.

This applies to built-in agent generation, including OpenRouter, OpenCode Go, and OpenAI. Decisions, image generation, and custom Go provider implementations keep their existing retry behavior.

## Readable observation and control IDs

Human-readable events now put typed IDs on their own line:

```text
[worker run=e5f6a7b8]
thinking: Preparing the answer.
```

Task startup also shows the corresponding agent ID. `noe agents` uses the same eight-character prefixes; `noe agents --full` shows complete IDs. Control commands accept unambiguous prefixes, and ambiguous targets report candidate IDs and names.

Context display is reduced to `context:0.2%`. Internal estimates, live snapshots, and automatic trimming remain current. Normal context events are emitted once when a model request completes, fails, or is cancelled, while applied trims retain their separate event. Detailed context data remains available in JSONL and structured snapshots.

The executable remains on the v1 release line. This does not publish a v2 Go module. Dependencies and the pinned go-quickjs engine are unchanged.

Full unit, E2E, race, and vet checks passed, along with all six target builds. Local HTTP fixtures verified transport recovery, incomplete streams, unchanged retry inputs, cancellation during waits, and no replay of tools or hooks. No real-provider request was required for this patch. Native execution is verified on Linux amd64; other targets have compilation evidence.
