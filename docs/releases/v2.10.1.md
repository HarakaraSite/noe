# NOE v2.10.1

This patch release fixes temporary-directory placement in the maintained
standard library. Public Go/JavaScript APIs and dependencies are unchanged.

## Preserve mkdtemp prefix directories

`node:fs.mkdtempSync` and `node:fs/promises.mkdtemp` now retain the supplied
prefix's parent directory. Previously, a prefix such as `/work/nested/run-`
could create `/tmp/run-<random>` without a filesystem root, or
`/run-<random>` inside a configured root. It now creates
`/work/nested/run-<random>` in the script's filesystem namespace.

Relative prefixes resolve against the configured filesystem cwd. A prefix
ending in a separator creates a randomly named directory inside that
location. Missing or non-directory parents fail rather than silently
selecting another location. Parent symlinks follow the existing filesystem
root policy, and ReadOnly continues to reject creation. Returned paths retain
the existing host-absolute or root-virtual form.

This is a NOE-local correction. Upstream issue filing is deferred.
See the [snapshot provenance](../../internal/stdlib/UPSTREAM.md).

## Verification and distribution

Regression tests exercise both synchronous and Promise APIs, rooted and
unrooted filesystems, absolute and relative prefixes, trailing separators,
empty and dot prefixes, missing/non-directory parents, symlinks and write
permissions. The existing implementation failed these placement tests;
after the fix, all `TestFiles` tests passed.

Release preparation reuses that implementation evidence. The unchanged
lightweight CI builds six CGO-free binaries, creates SHA256SUMS and publishes
the immutable tag. Published checksums, Linux amd64 mkdtemp behavior and
actual Go-module retrieval are verified after publication. Other targets
receive CI build/hash verification, without native execution here.

The verified published Linux amd64 binary is installed into repository-root
`./noe` and `/home/agent/.local/bin/noe`, with backups and atomic replacement.
Existing running processes are not restarted.

See the [release checkpoints](release-checkpoints.md).
