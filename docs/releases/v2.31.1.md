# NOE v2.31.1

## CLI timeout during startup

If the CLI's `--timeout` expires while setting up filesystem watching,
`noe run` and `noe eval` now report the execution timeout and exit with
code 124. A caller's parent deadline retains the ordinary error exit code.

The tests for timeouts after JavaScript starts use a virtual clock. A
separate regression test checks an expired deadline during watcher setup.

## Distribution

Linux, macOS, and Windows binaries for amd64 and arm64 are included with
`SHA256SUMS`. The Go module is
`forge.harakara.site/littleisland/noe/v2`.
