# NOE v2.26.0

This release updates both provider Go SDKs and removes redundant JSON encoding
when preparing Responses requests, incorporating implementation `33f5c39`.

## Provider SDK updates

- OpenAI Go SDK: v3.79.0 to v3.98.0.
- OpenRouter Go SDK: v0.9.61 to v0.9.116.

Existing OpenAI, OpenRouter and OpenCode Go HTTP/SSE routes, authentication,
Chat/Responses, Decisions and image generation contracts are preserved.
The update includes upstream API/type additions and fixes; NOE continues to
construct its own request JSON and retain native tool/reasoning history.
Go remains 1.27.2 and go-quickjs remains v0.37.1 with JIT disabled.

## Responses request construction

Responses previously generated a complete Chat request solely to validate it,
discarded that JSON, then constructed the actual Responses payload. Shared
validation now runs without the discarded encoding and returns normalized
effort to the request builder. Invalid model/cache-key UTF-8, invalid objects,
duplicate JSON names, effort/token limits and error behavior remain checked.

The optimization applies to both SDK adapters, including OpenCode Go's Responses
route. Public Go/JavaScript APIs and provider configuration are unchanged.

In a synthetic 256-message history with 4 KiB per message, median request
construction time decreased from 9.22 ms to 7.93 ms and cumulative allocated
bytes decreased from 14,927,254 to 10,928,036. Five alternating before/after
process pairs use identical SDK versions. This is a 14.0% local time reduction
and 26.8% allocation reduction; network, model and tool execution are excluded.
See the [implementation record](../development/agentlib-sdk-request-optimization.md)
for the other workloads, method and evidence.

## Verification and scope

Implementation checks cover provider and agent/public/bridge/executor suites,
focused CLI E2E, vet, module integrity and external Go consumers using both
checkout and independent module artifacts. Valid source results are reused for
release preparation. CI builds the six distribution binaries and SHA256SUMS
from the immutable tag without repeating source suites.

WebSocket continuation is retained as a
[deferred improvement idea](../development/agentlib-openai-websocket-idea.md);
this release does not enable it. Publication includes verified installation
at both existing vm201 executable paths, retaining the previous binaries.
See the [release checkpoints](release-checkpoints.md).
