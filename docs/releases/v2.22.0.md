# NOE v2.22.0

This release corrects existing AbortSignal/AbortController, text-stream,
compression-stream and URLPattern input contracts. It includes `edb5e73` and
`f1ad07a`. Dependencies, host capabilities and the Go `/v2` module path are unchanged.

## Cancellation and text streams

AbortSignal's public constructor is illegal; controller.signal is a branded
readonly getter backed by private state. Default abort and timeout reasons are
AbortError and TimeoutError DOMExceptions. onabort preserves registration order
and inert object-valued slots. timeout applies Web IDL EnforceRange conversion
through JavaScript's safe-integer bound (2^53-1), using staged deadlines over the
existing Loop queue and execution cleanup. Ordinary clearTimeout cannot cancel
these internal deadlines. Legacy WebAPIs installation without a Loop explicitly
rejects timeout; synchronous abort remains available.

TextEncoderStream/TextDecoderStream compose the existing TransformStream and UTF-8
codecs. Endpoints and metadata are branded readonly getters. The encoder preserves
UTF-16 surrogate pairs split across chunks, and the decoder requires BufferSources
and exposes fatal/ignoreBOM metadata. Additional encoding families are unsupported.

## Compression streams

Both constructors validate required formats synchronously before allocating native
work. Supported formats remain gzip, deflate and deflate-raw; Brotli is unsupported.
Endpoints are private readonly attributes. Writes require fixed non-shared
ArrayBuffers or views, snapshot exact spans, and reject strings/arrays/shared or
variable-length backing with TypeError. Detached backing contributes zero bytes.

Web decompression rejects forbidden gzip flags, zlib preset dictionaries, invalid
checksums, truncation, trailing bytes and extra gzip members. Writes wait for codec
progress, so a write containing invalid data rejects rather than succeeding before
a later read/close failure. Bounded native output backpressure, cancellation and
the existing 1 GiB cumulative output limit remain. Consume output concurrently;
incremental output can precede a later validation failure. Node zlib synchronous /
callback helpers retain their string convention; create* helpers use Web chunks.
Compression wrapper cloning rejects DataCloneError.

## URLPattern inputs

Constructor/test/exec accept URLPatternInit dictionaries, including baseURL, with
USVString conversion and standard component inheritance/defaults. Dictionary inputs
carry their own baseURL; combining them with the separate baseURL argument throws
TypeError. exec returns converted snapshots and real component captures. Constructor
parse failures throw; match parse failures return false/null. Conversion exceptions
propagate. Readonly branded component attributes, hasRegExpGroups and ignoreCase
options use private state. Pattern wrappers cannot be structured-cloned.

Empty relative strings, query/hash transitions, omitted passwords and relative
leading double slashes have corrected defaults. Shared URL normalization retains
empty path segments while removing dot segments. The retained compiler and URL
backend do not claim full pattern grammar, generated-pattern canonicalization or
IDNA conformance; dynamic dot-segment cases remain documented limits.

**Behavior compatibility:** use supported BufferSources for compression writes,
encode text first, carry dictionary baseURL inside the dictionary, and observe
readonly attributes and standard errors/reasons. Do not rely on discarded trailing
compressed data, additional gzip members, mutable controller/stream/pattern state,
split surrogate replacement, or the former AbortSignal constructor. Public types,
reference pages, examples and main/Worker Go consumers follow these contracts.

## Verification and distribution

Affected units, focused race, positive/negative types, reference catalog, lint/vet,
actual CLI primary/common/example checks and checkout/standalone-module consumers
pass. Independent bounded abort, URLPattern and compression reviews found issues
that were fixed and checked in one fix-only follow-up per review. Text-stream
internals were reviewed by the parent. No complete Web standards audit is claimed.

Release verification reuses unchanged implementation evidence. CI builds six
Linux/macOS/Windows amd64/arm64 binaries and SHA256SUMS from the immutable tag.
Native verification runs on Linux amd64; other assets receive checksum/build
metadata verification. Go 1.27.2, pinned go-quickjs v0.32.0 / go-intl v0.8.0,
CGO-disabled builds and disabled JIT remain selected.

Publication includes installing the verified native asset at both existing vm201
executable paths, retaining previous binaries. Other hosts, running services and
noebot are excluded. See [checkpoints](release-checkpoints.md),
[cancellation/text streams](../development/stdlib-abort-text-streams.md), and
[compression/URLPattern](../development/stdlib-compression-urlpattern.md).
