# NOE v1.8.0

This release adds owned file handles, raw sockets, OS signal subscriptions, and an API reference bundled with the executable.

## Files, sockets, and signals

- `noe:fs-handle` opens existing files in read-only or read/write mode and provides asynchronous positional `readAt`, `writeAt`, and `close` operations. Whole-file operations and sequential file streams remain available through the standard `node:fs` APIs.
- `noe:sockets` provides TCP and Unix stream connections and listeners using Web byte streams. Independent read/write directions support request EOF followed by a reply. Opening can be cancelled; explicit close and runtime shutdown reclaim owned connections and listeners.
- `noe:signals` exposes supported OS signals as asynchronous iterators. Linux and macOS support SIGHUP, SIGINT, SIGTERM, SIGUSR1, and SIGUSR2; Windows supports SIGINT. Notifications may coalesce. SIGINT still cancels the CLI, and a live SIGTERM subscription suppresses default process termination, including a subscription owned only by a Worker.

These modules work in main scripts, Workers, and agent `run_js` executions. Files, sockets, subscriptions, and subprocesses belong to their creating runtime. A fresh `run_js` process cannot leave them running independently after it ends. Explicit cleanup remains useful during normal execution. Unix listeners do not remove pre-existing paths; forced process termination may leave a socket pathname behind.

See the [I/O guide](https://forge.harakara.site/littleisland/noe/src/tag/v1.8.0/docs/low-level-io.md) and [examples](https://forge.harakara.site/littleisland/noe/src/tag/v1.8.0/examples/low-level/README.md).

## Built-in API reference

Read the English reference that matches the executable, offline and without credentials:

```sh
noe docs
noe docs node:fs
noe docs node:child_process execFile
noe docs noe:sockets connect
```

Scripts, Workers, and agents can read the same Markdown synchronously:

```js
import { docs } from "noe:docs";
console.log(docs("noe:fs-handle", "FileHandle.readAt"));
```

The catalog contains 40 topics and 98 detailed sections, covering NOE's public APIs, the `run_js` tool, all 26 supported stdlib modules, and globals. Stdlib documentation follows the pinned go-quickjs v0.27.0 implementation and NOE configuration, including important differences from Node.js. Some stdlib members have an export listing and module overview without individual details; a missing detail does not imply an unsupported API. Private agent helper modules are excluded from the public catalog.

Agent initial instructions now explain NOE's role, fresh-process execution, and how to discover API contracts. Detailed system-I/O instructions move to the bundled reference. Two real-provider tasks using OpenCode Go / `deepseek-v4.1-flash` consulted module overviews and individual details spontaneously, without being told to use docs in their task prompts, and completed positional file updates and TCP half-close communication. See the [reference guide](https://forge.harakara.site/littleisland/noe/src/tag/v1.8.0/docs/reference.md) and [validation record](https://forge.harakara.site/littleisland/noe/src/tag/v1.8.0/docs/development/builtin-docs-implementation.md).

Dependencies and the release profile are unchanged. Downloads cover Linux, macOS, and Windows on amd64 and arm64, with `SHA256SUMS`. Native execution is verified on Linux amd64; the other targets have cross-build evidence.
