# NOE v2.23.0

This release corrects URL/URLSearchParams normalization and encoding, then Request
URL/method handling. It includes `99f7f4b` and `68d9437`. Runtime dependencies,
host capabilities and the Go `/v2` module path are unchanged.

## URL and URLSearchParams

URL constructors, relative resolution and setters apply USVString conversion and
component-specific UTF-8 percent encoding. Existing escapes and empty segments /
query/fragment markers are preserved. Literal and encoded dot segments, supported
special-scheme slashes and default ports normalize consistently. Opaque paths stay
distinct from hierarchical paths; protected serialization avoids creating an
authority from a path. Argument conversion cannot leave setters using stale state.

searchParams retains its identity across href/search assignments. Parameter edits
update the linked query through private serialization. Form decoding replaces
malformed UTF-8 locally, preserves a BOM and distinguishes plus from space.
Iterable/record conversion, pair validation, optional value filters, readonly size,
stable UTF-16 sorting and live iteration follow the documented current Web IDL
slice. parse/canParse preserve conversion errors and report parsing failure.

## Request URL and method inputs

Public Request string/URL input uses the shared Web URL backend. Missing input,
invalid URLs and embedded credentials reject TypeError. NOE supplies no ambient
document base URL; resolve relative values explicitly. Request.url retains its
fragment; native HTTP serialization omits it on the wire.

Methods use ByteString and HTTP token validation. CONNECT/TRACE/TRACK reject.
Only DELETE/GET/HEAD/OPTIONS/POST/PUT normalize to uppercase; extension methods such
as patch retain their case, including at native HTTP dispatch. Empty methods no
longer fall back to GET. url/method are branded readonly getters; copy/clone/fetch
use private metadata even when visible properties shadow getters. Current copy /
clone metadata is preserved. Invalid URL/method does not acquire the upload body.

Incoming noe:http requests use a private per-runtime factory over the same Request
implementation, preserving native methods/raw URLs and clone/transfer ownership.
The factory is not published and is removed on runtime close. Both installer orders
work. Legacy Network can install before WebAPIs; Request construction requires the
Web URL backend when called.

**Behavior compatibility:** callers now receive encoded URL components, one live
query object and readonly Request URL/method. Use form encoding only where form
semantics are intended. Provide valid methods and credential-free absolute URLs;
spell extension-method case explicitly when the peer distinguishes it. Code that
relied on stale query references, malformed-query fallback, forced uppercase patch,
empty methods or writable Request URL/method must adapt. Types, embedded references,
examples, libraries and main/Worker consumer checks follow the corrected surface.

## Scope and verification

The existing URL parser/codecs, body/streams, transport, Allow policy and execution
ownership are retained. Full UTS46/IDNA, IP parsing/canonicalization, Windows file
URL quirks and complete URLPattern/Headers/Body/RequestInit/signal/browser-policy
conformance remain outside these corrections. Current primary-spec differences
from Deno/Node are recorded rather than weakening assertions.

Affected packages, focused race, declarations/catalog/lint/vet, actual CLI cases
and checkout/standalone-module main/Worker consumers pass. An unchanged prepared
MCP SDK loopback fixture passes initialize/list and three parallel Unicode echo
calls without external services. Independent bounded reviews verified the fixes,
incoming factory privacy/lifetime and both Network/Servers installer orders.

Release verification reuses unchanged implementation evidence. CI builds six
Linux/macOS/Windows amd64/arm64 binaries and SHA256SUMS from an immutable tag without
repeating source suites. Native verification is Linux amd64; other assets receive
checksum/build metadata verification. Go 1.27.2, pinned go-quickjs v0.32.0 /
go-intl v0.8.0, CGO-disabled builds and disabled JIT remain selected.

Publication includes verified installation at both existing vm201 paths with old
binaries retained. Other hosts, running services and noebot are excluded. See the
[release checkpoints](release-checkpoints.md), [URL/query record](../development/stdlib-url-encoding.md)
and [Request record](../development/stdlib-request-inputs.md).
