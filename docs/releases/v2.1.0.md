# NOE v2.1.0

NOE upgrades its JavaScript engine from go-quickjs v0.27.0 to v0.28.0.
The experimental JIT remains disabled in standard builds. Existing CLI commands,
JavaScript modules and public Go API signatures are unchanged.

## Engine update

The upstream interpreter includes a new BigInt arithmetic implementation and
changes to object layouts and property caches. It also corrects primitive
property deletion to follow ECMAScript: deleting a string's non-configurable
`length` property returns false in non-strict code and throws a TypeError in
strict code. See the [upstream release](https://github.com/go-quickjs/go-quickjs/releases/tag/v0.28.0).

NOE adds neither the `quickjs_jit` build tag nor `quickjs.WithJIT()`.
This release makes no claim of a measured speedup for NOE agent workloads.
Go 1.27.2, go-intl v0.6.1 and the model-provider dependencies are unchanged.

NOE's maintained standard library retains its v0.27.0 source origin and local
improvements. It has not been replaced with an upstream snapshot. The engine
version and the standard-library source origin are separate; see
[Go embedding](../go-embedding.md) and the [API guide](../api.md).

## Test reliability

A Linux owner-death test now recognizes `ESRCH` when a process disappears
between opening and reading `/proc/PID/stat`. The same failure was reproduced
with the previous engine. Only the post-stop observation was corrected;
pre-stop errors, permission errors, live processes and timeouts still fail.
No production process-supervision behavior changed.

## Validation

The engine adoption passed normal and critical plan/code reviews, the full
unit/E2E suite, race checks, sustained Go Client waits and cancellation, vet,
and compilation for all six distribution targets. Separate stdlib and agent
consumers built and ran through local and synthetic-artifact module paths,
selecting v0.28.0 even when the consumer requested the older engine.

NOE CLI smoke checks covered BigInt values beyond 64 bits, BigInt Worker
round trips, warmed property-cache updates, dynamic properties, delete/freeze,
and the strict primitive-delete correction. Local model fixtures covered
managed agent/tool executions without paid provider calls.

See the [adoption plan and evidence](../development/go-quickjs-v0.28.0-plan.md)
and [release checkpoints](release-checkpoints.md) for source revisions and
publication checks. Native execution was tested on Linux amd64; the other
targets have compilation/build evidence. JIT execution and workload performance
were not tested.
