# NOE v1.3.2

NOE updates eight dependencies after individual and combined compatibility checks. Agent startup, provider configuration, and JavaScript APIs remain unchanged.

## Improvements and compatibility

go-intl improves Unicode normalization and collation, and fixes shared references in locale results. In five paired NOE measurements on Linux amd64, the supplied Latin-text NFD workload was about 2.34 times faster and the Japanese-text workload about 1.29 times faster at the median. These are specific string-processing measurements, not overall agent-task speedups.

The JSON updates fix integer overflow conversion, escaped-string in-place compaction, and cloned-node parent references. Out-of-range integer conversion now saturates rather than wrapping. Invalid UTF-8 may have a different JSON spelling while decoding to the same replacement character. NOE and its SDKs do not use the deprecated GJSON globals whose effects changed.

The OpenRouter SDK update mainly changes Batch models and documentation; NOE's Chat, Responses, and Decisions paths passed their fixtures. Terminal and OS dependency updates passed NOE's input, interruption, and terminal-restoration checks. No NOE implementation changes were needed.

See the [dependency validation record](https://forge.harakara.site/littleisland/noe/src/tag/v1.3.2/docs/development/dependency-updates.md) for versions, measured workloads, intentional behavior changes, and test evidence.

## Validation and downloads

All eight candidates passed individual compatibility checks, followed by full combined tests and six cross-builds. The final release checks and published-asset verification are recorded in the [release checkpoints](https://forge.harakara.site/littleisland/noe/src/tag/v1.3.2/docs/releases/release-checkpoints.md). No real model-provider request was needed for this dependency release.

Standalone binaries cover Linux, macOS, and Windows on amd64 and arm64, with `SHA256SUMS`. Linux amd64 is tested natively; other platforms are cross-compiled. See the [README](https://forge.harakara.site/littleisland/noe/src/tag/v1.3.2/README.md) or [Japanese README](https://forge.harakara.site/littleisland/noe/src/tag/v1.3.2/README.ja.md) for setup.
