# NOE v2.33.0

An agent's owner can add, replace, and remove named system instructions
while the instance is running or idle.

- JavaScript exposes `set_agent_instruction` and `remove_agent_instruction`
  in `noe:agent`.
- Go exposes `SetInstruction` and `RemoveInstruction` on the agent Client
  and Host.

Each model step uses the instructions active at its start. The instructions
survive context trimming and queued tasks for the lifetime of the instance.
The instruction files and `config.system` loaded at the first task form
the base system message. [Usage and examples](../instructions.md#updating-a-live-instance)

Download CGO-free binaries for Linux, macOS, and Windows on amd64 and arm64,
along with `SHA256SUMS`. The Go module is
`forge.harakara.site/littleisland/noe/v2`.
