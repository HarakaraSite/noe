# NOE v1.3.3

This patch release reorganizes agent internals and end-to-end tests for easier maintenance. JavaScript APIs and runtime behavior are preserved, and dependency versions are unchanged from v1.3.2.

## Maintenance

- Split the agent broker into transport/RPC, run management, steering and final-answer coordination, model calls, JavaScript execution, and event reporting.
- Separate SSE reading, readable stream observations, and response accumulation.
- Separate recorded-run observation into query handling, log reading, state reconstruction, and event projection.
- Keep all 107 original implementation declarations, including their bodies and attached comments, unchanged while moving them to their corresponding files.
- Separate E2E build setup and shared CLI helpers, consolidate process execution, and organize REPL tests by history, multiline input, completion, and editing behavior.
- Read the OpenRouter SDK version from the tested CLI binary when recording live acceptance results, instead of reporting a hardcoded version.
- Add an [E2E test guide](https://forge.harakara.site/littleisland/noe/src/tag/v1.3.3/tests/README.md).
- Move the arbitrary-task agent example to `examples/try-agent.js` and update README links and commands.

## Validation and downloads

Release checks include unit tests, E2E tests with Linux PTY interactions, vet, race detection, and all six distribution builds. Provider tests use local fixtures; this maintenance release does not require real model requests. See the [release checkpoints](https://forge.harakara.site/littleisland/noe/src/tag/v1.3.3/docs/release-checkpoints.md) for the preparation record.

Standalone binaries cover Linux, macOS, and Windows on amd64 and arm64, with `SHA256SUMS`. Linux amd64 is tested natively; the other targets are cross-compiled. See the [README](https://forge.harakara.site/littleisland/noe/src/tag/v1.3.3/README.md) or [Japanese README](https://forge.harakara.site/littleisland/noe/src/tag/v1.3.3/README.ja.md) for setup.
