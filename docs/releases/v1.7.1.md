# NOE v1.7.1

This maintenance release bounds captured agent output and makes the agent implementation easier to navigate.

## Bounded agent output

Captured `run_js` stdout and stderr each retain up to 64 KiB of original output: the first 32 KiB and last 32 KiB. Larger output includes an explicit truncation marker and `stdoutOmittedBytes` or `stderrOmittedBytes`. Results, hooks, and JSONL receive the bounded output and omission metadata. UTF-8 truncation boundaries preserve complete characters.

The runner continues draining both streams after reaching the retention limit, so verbose commands can finish without blocking their output pipes. Truncation alone does not change the exit code or completion status. Internal managed-task process output uses the same bound. Top-level script output is unchanged.

Omitted output is not saved automatically. Write complete logs to a file from the script or command when needed, then read the relevant portions.

## Internal organization

- Separate configuration, Host, Operation, instance state, task execution, ownership checks, and event publication into files with clear responsibilities.
- Separate HTTP handlers from typed spawn, observe/wait, queue, steer, and interrupt operations, retaining the existing RPC responses and event ordering.
- Extract OS process execution and bounded output collection into `internal/agent/runner`, retaining NOE-specific bootstrap, import-map preparation, and environment construction in the parent package.
- Add an architecture guide and slice-by-slice implementation and review records. Preserve public APIs, shared locking, cancellation, queue continuation, conversation/image ownership, and provider behavior.
- Make the supervised-process cleanup test wait for asynchronous process reaping.

See the [architecture guide](https://forge.harakara.site/littleisland/noe/src/tag/v1.7.1/docs/development/agent-architecture.md), [implementation checks](https://forge.harakara.site/littleisland/noe/src/tag/v1.7.1/docs/development/agent-refactor-implementation.md), [output/event contract](https://forge.harakara.site/littleisland/noe/src/tag/v1.7.1/docs/events.md), and [release checks](https://forge.harakara.site/littleisland/noe/src/tag/v1.7.1/docs/releases/release-checkpoints.md).

Dependencies and the release profile are unchanged. Downloads cover Linux, macOS, and Windows on amd64 and arm64, with `SHA256SUMS`; native execution is checked on Linux amd64. No additional real-provider requests are required for this maintenance release.
