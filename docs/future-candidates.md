# NOE 次の機能候補

NOE v1.0.0以降の候補として、外部コマンド、ストリーミング、import map、HTTP URLからのimportを検討する。以下は優先順の案で、詳細仕様とインクリメントの範囲は着手時に決める。

## 優先順の案

| 順番 | テーマ | 目的 | 最初に検討する範囲 |
| --- | --- | --- | --- |
| 1 | 外部コマンド | 既存ツールとファイル・HTTP処理を組み合わせる | コマンドと引数、stdin、stdout・stderr、終了コード、実行中断 |
| 2 | ストリーミング | 大きなファイルやHTTP bodyを全量保持せず扱う | ファイルとHTTPクライアントの段階的な読取り・書込み |
| 3 | import map | ローカルモジュールに名前を付け、配置変更を吸収する | CLIで指定するimport mapとローカルファイルの解決 |
| 4 | HTTP URLからのimport | URLで公開されたJSモジュールを読み込む | モジュール取得、URL基準の相対import、キャッシュ、取得失敗の扱い |

次のインクリメントの第一候補は外部コマンドとする。

ストリーミングは、ファイル・HTTPクライアントから始め、HTTPサーバーへの対応を別の段階に分けられる。import mapとHTTP importは関連するが、別インクリメントとして仕様を確かめる案とする。

## 保留と製品方針

暗号・ハッシュは要検討。具体的な用途が出た段階で、ハッシュだけ必要か、暗号処理まで必要かを判断する。

TypeScript対応は引き続き後回しとする。npm対応・Node/Deno互換は実装しない方針を維持し、実際に必要な機能を選んで追加する。
