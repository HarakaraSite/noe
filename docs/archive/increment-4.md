> **初期開発の履歴です。** 旧APIや当時の対象範囲・検証結果を含みます。現在の使い方は[利用ガイド一覧](../README.md)、記録の一覧は[archive](README.md)を参照してください。

> この文書は実装当時の計画・検証記録です。現在の仕様は[APIリファレンス](../api.md)と[stdlib移行記録](increment-12.md)を参照してください。旧`noe.*` API、独自I/O実装、当時の対象外・中断動作は現行仕様ではありません。

インクリメント4では、liner v1.2.3を使うREPLへ、履歴保存、前回結果、複数行入力、中断後の続行、JSのTab補完を追加した。状態は全スライスの実装・レビュー・総合E2E完了。前提は[インクリメント3](increment-3.md)の完了したREPL。名称変更とTypeScript対応は保留する。

## 操作の契約

| 項目 | 動作 |
| --- | --- |
| 履歴保存 | 対応する対話端末だけで保存する。既定はGoのUserConfigDir以下の`noe/repl_history.jsonl`。`NOE_REPL_HISTORY`で保存先を指定し、空文字なら保存・読込みを無効にする。非端末入力は履歴ファイルを扱わない |
| 保存形式 | 確定した入力全体をJSON文字列の1行として追記する。複数行も1件。空白だけの入力と破棄した入力は追加しない。メモリに保持する履歴はlinerの上限1000件。既存ファイルを上書きしないので複数セッションの追記を残せる |
| 保存失敗 | 読込み・保存失敗を標準エラーへ通知し、REPLを続ける。そのセッションの履歴は引き続き使える。壊れた履歴行は通知して読み飛ばし、元ファイルは削除しない |
| 前回結果 | `_`は最後に成功した、undefined以外の評価結果。最初はundefined。エラー・中断・undefinedは直前の結果を維持。オブジェクトの参照を保持し、ユーザーによる代入も可能 |
| 複数行 | エンジンの構文確認で未完の入力を判別し、`... `で続ける。関数・オブジェクト・括弧・テンプレート・ブロックコメントなどを対象にし、確定した構文エラーはその場で診断する |
| 非同期入力 | 現在の1つのawait式、単一変数の初期化・代入は改行を含んでも使える。任意の複数文await変換や分割代入へは広げない |
| 入力の中止 | 対応する対話端末でCtrl+Cを押すと、編集中の入力・継続入力を破棄して`> `へ戻る。空の入力でも終了しない |
| 評価の中断 | 対応する対話端末でCtrl+Cを押すと、その入力のJS・HTTPなどを中断し、後始末後に次の入力へ進む。変数や関数、中断前の変更は維持する。ファイルの変更は巻き戻さない |
| EOF | 空の対話入力でCtrl+Dはコード0で終了。未完の入力でEOFの場合は構文診断を出してコード0で終了する。パイプの改行なし最終入力は従来どおり評価する |
| 明示終了 | `noe.exit(code)`は従来どおり即座に指定コードで終了する |
| 外部キャンセル | 呼出し元contextのキャンセルと、入力待ちでの外部SIGINTはプロセスを130で終了する。非端末のSIGINTも従来どおり130。端末で評価中のSIGINTはCtrl+Cと同じ入力中断として扱う |
| 補完 | キーワード、グローバル名、成功した入力のトップレベルlet/const宣言名、識別子のドット列のプロパティを補完する。let/constの分割代入と日本語名を含め、関数・varはグローバル名から取得する。失敗入力の部分宣言やエスケープ表記の名前収集、任意の式・関数呼出し・添字の補完へは広げない。getterを呼ばず、候補取得の失敗は通常入力へ戻す |

複数行の履歴呼出しと再表示は製品PTYで確認する。linerの行編集へ接続し、独自の端末エディタは作らない。続行時には`Interrupted`を標準エラーへ表示する。終了操作はCtrl+Dと`noe.exit()`で案内する。

## 実装方針

SessionはJSランタイムを所有するgoroutineだけから呼ぶ。入力の読み取りは既存の別goroutineを使い、行編集ライブラリの補完コールバックは要求を評価ループへ送る。評価ループが候補を取得して返し、入力側で直接エンジンを操作しない。

プロセスのcontextと1入力のcontextを分ける。対話REPLのシグナルは入力待ちと評価中で扱いを分け、通常のrun/evalと非端末REPLの終了契約を維持する。中断ではSessionを作り直さず、現在の入力に属するホストI/Oをキャンセルし、ランタイムへの完了通知とJSジョブの接続を終えてから次のプロンプトへ戻す。固定エンジンの公開APIで接続し、エンジンのforkや変更を前提にしない。

ファイルのopen/read/writeも入力contextへ接続する。名前付きパイプのようにOSの同期openが待つ場合でも、入力のキャンセルでREPLは先へ進み、遅れてopenが成立したファイルは読み書きせず閉じる。既に始まったOSの同期syscallそのものを強制停止する保証はしない。キャンセル済みの仕事が後で完了してもJSの値や反応を実行しない。

補完の名前とプロパティは、JSの記述情報と利用可能な宣言から取得する。getterを呼ばない。Proxyの記述情報取得はユーザーのtrapを実行し得るため短いcontextで制限し、失敗時は候補なしで戻す。候補取得で通常の評価結果や`_`を変更しない。使う組み込みヘルパーは通常入力の上書きから分けて保持する。

履歴は入力の読み取り時ではなく、複数行が確定した時点で追加する。保存先の設定は端末アダプターへ渡す。ファイルは追記で作成し、作成時の権限は0600。読込みは1行ずつ行い、メモリに残す件数を制限する。別DB、履歴の自動削除・保存ファイルの自動切詰めは導入しない。

## スライスと受入条件

| スライス | 実装 | 完了条件 |
| --- | --- | --- |
| 1 | 履歴の永続化と`_` | 再起動後に履歴から実行できる。保存を無効にでき、保存失敗後も操作できる。成功・失敗・undefined・非同期結果とオブジェクト参照で`_`が契約どおり動く |
| 2 | 構文確認と複数行入力 | 数行の関数、オブジェクト、文字列などを確定して一度だけ評価する。確定エラーは即診断。未完の入力は実行しない。EOF直前の入力と既存await範囲を維持し、複数行履歴を1件として再実行できる |
| 3 | 入力の破棄と評価中断後の続行 | 入力中・履歴検索中・継続入力中・無限ループ評価中・HTTP待ちの実Ctrl+C後に同じ変数を使って次の評価を実行できる。前のI/O・JSジョブ・診断が次の入力へ混ざらない。EOF・明示終了・非端末SIGINTのコードと端末復元を維持する |
| 4 | JSのTab補完 | `noe.re`、`console.lo`、宣言した名前、オブジェクトのプロパティが補完できる。getterが動かない。失敗・Proxyの中断後も入力でき、JSへの並行アクセスがない |
| 5 | 利用説明と総合E2E | READMEの新しい操作を説明し、製品PTYの操作検証と既存run/eval/REPLを含む全E2Eが成功する |

各スライスで実装・目的に対応するテスト・レビューを行う。小さな履歴保存・入力変換はrootが確認し、Sessionのキャンセルと端末の続行・補完の所有に独立したレビューを使う。レビューは対象と受入条件へ限定し、必須指摘を解消する。スライスの境目でGoテストとCGO無効のビルドを確認する。

## 検証

履歴は一時ディレクトリで検証し、利用者の通常履歴へテスト入力を保存しない。HTTPはローカルサーバー。中断・補完のgoroutine接続はCLIとruntimeのrace検査を行う。

最後に`go test -tags=e2e ./... -count=1 -v`を実行する。PTYは実バイナリで、入力エコーとは区別した評価結果、次のプロンプト、終了コードと終了後のtermiosを確認する。割込み前には評価開始・HTTP開始を待つ。既に了承された全角文字の右端残り1列の実端末表示と、他OSの表示検証は今回の新しい必須条件にしない。

## 対象外

TypeScript、名称変更、npm・Node/Deno互換、Web標準全面互換、REPLの静的import、任意の非同期ソース変換、TUIフレームワーク、画面分割、独自の全画面エディタ、独自のUndo/Redo・自動インデントは対象外。

## 総合検証の結果

Go 1.27.2、Linux amd64で以下が成功した。

- スライスのGoテスト、CGO無効ビルド、CLI・runtimeのrace検査。
- 製品PTYでの履歴保存と再起動、無効化、`_`、複数行入力と履歴再実行、Tab補完・日本語名・getter非実行、失敗後の入力続行。
- 入力・履歴検索・継続入力・JS評価・HTTP待ちの実際のCtrl+C後の続行と状態保持。非端末と入力待ちでの外部SIGINTの130終了、EOFの0、明示終了の指定コード、終了後のtermios復元。
- race付きの実バイナリでTab補完、補完中の明示終了、JS/HTTP中断後の続行。テストのCLIビルドだけを/tmpのoverlayでrace用へ変更して確認し、リポジトリの通常E2EはCGO無効のまま維持。
- 全スライスレビュー後の`go test -tags=e2e ./... -count=1 -v`。既存run/eval・API・REPLと新しい操作の全テストが成功。
- `go vet ./...`、`gofmt -l cmd internal tests`、`git diff --check`。指摘・未整形ファイル・空白エラーなし。

履歴とHTTPは一時ファイル・ローカルサーバーで確認した。利用者の通常履歴や外部サービスをテストに使わない。全角文字が右端の残り1列へかかる実端末表示と他OSの表示検証は、以前からの未確認事項を引き継ぐ。

リポジトリ直下の`noe`を最新ソースでCGO無効ビルド済み。`./noe repl`で試せる。対話端末でのCtrl+Cは今後は中断と続行になり、終了には空入力でのCtrl+Dまたは`noe.exit()`を使う。
