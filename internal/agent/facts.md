An agent task may use the `run_js` tool to execute a normal ES module with top-level await. Import every API explicitly; no agent helpers are prebound. Return data with `export default value` or `export default await operation()`. A final expression is not returned. Each invocation runs in a fresh owned JavaScript runtime with a new global scope and module cache. Relative imports from the virtual entry resolve from the execution's configured working directory; file-backed modules resolve relative imports from their importing module.

Available runtime APIs depend on the selected profile. Use `describe(topic?, member?)` from `noe:docs` for runtime exports, availability, and explicitly documented signatures; `docs(topic?, member?)` returns detailed reference text. A missing detail or signature does not imply an unavailable API. `check(code)` from `noe:runtime` inspects a fresh static module graph without evaluating module bodies and returns `{ok, stage, entry, diagnostics?}`.

The `run_js` result reports optional structured data, stdout, stderr, exitCode, reason, phase, and structured diagnostics on failure. Diagnostic classification is separate from a user exception code. A serialize failure can follow executed side effects; do not automatically repeat such operations. Default-exported Promises are rejected; await them explicitly. Captured stdout and stderr each retain the first and last 32 KiB and report omitted bytes when truncated. `NOE_CONTEXT_STATUS` is a user message in conversation history.

The `noe:agent` module exposes `run_agent`, `spawn_agent`, `observe_agent`, `queue_agent`, `wait_task`, `read_task_result`, `read_tool_result`, `steer_agent`, `cancel_task`, `stop_agent`, and `list_models`. Agent and task operations are checked against the current execution's ownership scope. `spawn_agent` and `queue_agent` return accepted command identifiers; `wait_task` observes one command's retained result. `cancel_task` cancels one command, while `stop_agent` stops an instance and its remaining work.

Large data or captured streams include resultRef and omitted-byte counts. Import read_tool_result from noe:agent to read the original result JSON within the same active task; pages default to 24 KiB (explicit limit 4–65536 bytes). Use nextOffset to continue from a UTF-8 boundary. References expire at task completion; save files needed later before finishing. A resultRef refers to actual execution output, before afterTool transformations.
