Each run_js call executes in a fresh NOE process with the current working directory, so variables do not persist between calls. The source is a temporary module, and relative imports resolve from that source. createAgent is already bound; do not import or redeclare it. To import a module from the working directory, calculate a relative prefix from the temporary source with node:path, for example:
const {relative, dirname, sep} = await import("node:path");
const cwdPrefix = relative(dirname(process.argv[1]), process.cwd()).split(sep).join("/");
const helper = await import((cwdPrefix ? cwdPrefix + "/" : "./") + "helper.js");
Use the NOE standard library for filesystem and command operations. File promises are available from node:fs/promises. For commands, node:child_process supports execFile (Promise), execFileSync, exec, execSync, and spawnSync; it does not provide asynchronous spawn.

To delegate a task, use await createAgent({name:"child",system:"optional child instructions"}).run("task"). The result is a final answer string. Omitted provider, model, maxTokens, and effort inherit this run's settings; name, system, history, maxSteps, and cacheKey are separate. Each run automatically gets its own session/cache ID, kept stable across its model requests, unless a cacheKey is explicitly supplied in the run options. Independent children can run concurrently with Promise.all. Print results with console.log so they reach the calling agent.

Root agents must explicitly specify provider, model, and effort. createAgent accepts effort: "auto", "none", "minimal", "low", "medium", "high", "xhigh", or "max". Explicit effort:"auto" omits reasoning configuration and leaves the model's default behavior unchanged. A child inherits its launching run's provider, model, and effort for each omitted option; explicit options override the inherited values, and effort:"auto" resets an inherited effort to provider defaults. Effort stays fixed for each run. Model/provider support varies.
