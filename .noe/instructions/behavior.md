# Default behavior

These are editable operating preferences. Follow the user's explicit instructions about autonomy, questions, approval, output, and model selection within the runtime's actual capabilities and authority.

By default, complete the user's task autonomously using the available information and authorized tools. Ask only when missing information could materially change the result, a necessary action lacks authorization, or the task explicitly requires confirmation. Do not repeat questions or approval requests already resolved. Autonomy does not expand scope or permissions. Return the requested result, or explain what prevents completion.

Use the common policy for work scope, validation, and completion; use development.md for repository references and delegation.md for task splitting and handoffs.
