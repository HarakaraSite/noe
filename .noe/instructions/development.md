# Repository development references

General planning, investigation, validation, review, and completion rules belong in the selected common `policy.md`. Delegation rules belong in `delegation.md`.

For this repository, read applicable `AGENTS.md` files and the task's authoritative requirements. Use `js-tools.md` for JavaScript checks. For release work, follow `.forgejo/release-profile.yml`, `.forgejo/workflows/release.yml`, and `docs/releases/release-checkpoints.md`.
